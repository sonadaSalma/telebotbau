# Aka Telegram Bot 🤖

**Aka** هو بوت تليجرام برمجته خلال سنتي الجامعية الثانية بهدف مساعدة الطلاب في الحصول على **ملخصات، كتب، وأسئلة سنوات** لموادهم الجامعية بسهولة ومن غير إحراج تكرار طلب المساعدة من الآخرين.

هذا المشروع كان رحلة تعلم مليئة بالتحديات التقنية والتجارب لاستضافة البوت مجانًا.

---

## ⭐ ميزات Aka:

* يرد على رسائل محددة.
* يرسل للمستخدم:

  * ملخصات المواد
  * كتب وملخصات
  * أسئلة سنوات سابقة
* سريع وبسيط في التعامل.

---

## 📚 التقنيات المستخدمة:

* Python 3.9.7
* pyTelegramBotAPI Library
* GitHub Actions (لتشغيل البوت مجانًا سابقًا)
* Replit / PythonAnywhere / Railway (محاولات استضافة سابقة)

---

## 🚀 كيف تشغّل Aka محليًا:

1. تأكد من تنصيب Python 3.9.7 على جهازك.
2. ثبّت المكتبات المطلوبة:

   ```bash
   pip install pyTelegramBotAPI 
   ```
3. أنشئ بوت جديد عبر BotFather في تليجرام واحصل على الـ **Bot Token**.
4. عدّل الكود وضع التوكن الخاص بك بدلًا من `YOUR_TOKEN_HERE`.
5. شغّل الملف الرئيسي:

   ```bash
   python myBot.py
   ```
